# Stelbit

**A private cross-device mesh, distributed workbench, and system-level backbone for autonomous, peer-like AI.**

## Layer 1 — Core Infrastructure (Active Build: v0.4)
- **Private Cross-Device Mesh:** Links local PCs, Android devices, and multi-carrier links into a unified internal web, engineered for future remote expansion.
- **Distributed Workbench (`internetChunk` · `mediatorChunk` · `employerChunk`):** Pools fragmented CPU, storage, and multi-carrier cellular bandwidth to distribute tasks across constrained consumer hardware.
- **Minimal SaaS Control Plane:** Lightweight dark-mode interface for real-time node visibility and orchestration *(live demo uploading today)*.

## Layer 2 — Integrated Ecosystem & Ongoing Research (Unlocked by Stelbit)
1. **System-Level Agent Backbone:** Gives an autonomous software agent native visibility, control, and regulation across every connected device.
2. **Cognitive AI Companion:** Moves beyond passive, prompt-obeying bots toward an opinionated daily AI peer with deep cross-device context, independent perspective, and collaborative pushback.
3. **Efficiency & Security Subsystems:** Ongoing architectural work in bio-inspired low-overhead data encoding, thermal/latency-aware AI routing, and hardened local workload safeguards.
