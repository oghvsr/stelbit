# StelBit

**A private cross-device mesh, distributed compute workbench, and system-level backbone for autonomous, peer-like AI on constrained consumer hardware.**

> **Current Build Status (Honest Snapshot):** StelBit is a solo independent build actively transitioning from a raw, functional **v0.3** prototype into a redesigned **v0.4** unified control plane. Built directly on legacy consumer hardware (older Windows PCs, repurposed Android phones, and multi-carrier cellular links) rather than cloud VMs.

## Part 2 — StelBit v0.4 (Under Construction · UI & Control Plane Overhaul)
*(Drag & drop `Homei_3.png` here)*

StelBit v0.4 restructures the raw v0.3 foundation into a pitch-black OLED control plane designed for live cross-device orchestration:
- **Live Storage Sharding (`sharding` toggle):** Exposes live-accessible shared storage across paired local devices.
- **Mesh Pairing Switch (`JOIN · 2 servers`):** Connects local nodes into a unified internal web with live per-device uptime tracking (`Home` panel) and network circulation telemetry.
- **Conditional Task Feedback:** Minimal indicators (`thinking` timer, `>3s slow` latency badge, and 16-dot server sync progress) that stay invisible until a task or handshake actually requires them.
- **Dynamic Island Navigation Centre:** Unified dock spanning `Home`, `Devices`, `Cloud`, and two reserved slots (`Agent` and `Command Line`) built for the upcoming intelligence layers.

## Integrated Vision — What StelBit Unlocks (Layer 2 · Roadmap & Research)
*(Optional: drag & drop your vision/architecture diagram here)*

StelBit is not meant to remain a standalone local utility—it is the hardware-level substrate for four integrated modules:
1. **System-Level Agent Backbone:** Gives an autonomous software agent native visibility, task dispatch, and regulation across every connected device.
2. **Cognitive AI Companion (Not a Servant Bot):** Uses deep cross-device context to power an opinionated daily AI peer capable of independent thought, perspective, and real pushback.
3. **Bio-Inspired Low-Overhead Encoding:** Compact data structures aimed at cutting cross-node bandwidth bottlenecks on constrained links.
4. **Thermal-Aware Routing & Local Safeguards:** Heat- and latency-aware AI routing paired with strict on-device privacy protocols—engineered to scale from a local internal web to remote trusted devices.
